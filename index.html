Open source · Apache 2.0

A deterministic validator for AI-generated code.

Reproducible. Multi-stack. Quiet enough to run in your pipeline. Aegis runs a layered check pipeline against generated code and reports whether it's shippable — most layers deterministic, a couple LLM-judged only where they earn their place.

What it does

A multi-layer pipeline: AST checks, cross-file consistency, dependency and package install, type-check, test runners, then an LLM-judged design-fidelity pass with a deterministic override. Output: ship, or an honest FAILED.

Stacks today

Python, Node.js (TypeScript / JavaScript), and static HTML.

Reproducible

A public benchmark cohort (aegis-bench) — any machine, same cases, same results. The output is the evidence.

Open source

Apache 2.0, on PyPI today. pip install aegis-validator and run it against your own code.

pip install aegis-validator
aegis check ./your-code
