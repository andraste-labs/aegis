The method

Generated is not the same as verified.

Aegis treats a codebase as a connected system. Cheap structural checks run first; builds, tests and semantic checks follow only where they apply.

01 / Detect

Read the project

Aegis detects Python, Node.js, TypeScript, JavaScript and static HTML surfaces before selecting applicable checks.

02 / Verify

Run the layers

Syntax, imports, dependencies, cross-file contracts, builds and tests are evaluated in a repeatable order.

03 / Report

Return the evidence

You receive a clear pass or fail, stack detection, timings and the exact layer evidence behind the verdict.
